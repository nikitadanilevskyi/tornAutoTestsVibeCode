# Torn Auto-Tests

Playwright auto-tests for the Torn web application.

## What this suite covers

| Folder | Coverage |
|---|---|
| [`e2e/money-input/`](e2e/money-input/) | Generic `tornInputMoney` plugin behaviour across 39 page surfaces (~700 scenarios) — formatter, validation, shortcuts (`k/m/b/max/half/quarter/%/N/M/$prefix`), keyboard, symbol button, accessibility, mode switching, confirmation flow, height across viewports/zooms |
| [`e2e/money-input-traveling/`](e2e/money-input-traveling/) | Money inputs only reachable when the player is currently abroad (Travel Abroad Shop, Cayman Bank deposit/withdraw) |
| [`e2e/money-input/ajax-lifecycle.spec.ts`](e2e/money-input/ajax-lifecycle.spec.ts) + [`plugin-lifecycle.spec.ts`](e2e/money-input/plugin-lifecycle.spec.ts) | Branch `21446-money-ajax-requests` lifecycle fixes — AJAX dedup, `visibilitychange` namespace, `isFormatting` recursion guard, `destroy()` cleanup |

## Setup

```bash
# 1. Install dependencies
npm install                  # or: yarn

# 2. Copy and fill in environment variables
cp .env.example .env
# Edit .env to set TORN_EMAIL / TORN_PASSWORD / TORN_HTTP_USER / TORN_HTTP_PASS

# 3. Install Playwright browsers (first run only)
npx playwright install chromium
```

## Running tests

```bash
# Full suite (re-authenticates via global-setup.js on every run)
npm test

# Use the cached session (skip re-auth) — faster, recommended when iterating
npm run test:no-setup

# Targeted subsets
npm run test:money-input        # general money-input across 39 surfaces
npm run test:traveling           # only when account is abroad in Cayman
npm run test:rspack-migration    # branch-specific rspack regression checks
npm run test:lifecycle           # branch-specific 21446 lifecycle suite

# Open the HTML report after a run
npm run report
```

### Direct invocation

```bash
# Single spec
npx playwright test --config=playwright.config.no-setup.js \
  e2e/money-input/edge-cases.spec.ts

# Filter by test title
npx playwright test --config=playwright.config.no-setup.js \
  e2e/money-input/ -g "S-43"

# List tests without running
npx playwright test --config=playwright.config.no-setup.js \
  e2e/money-input/ --list
```

## Two configs — when to use which

| Config | Behaviour |
|---|---|
| `playwright.config.js` (default) | Runs `global-setup.js` to log in fresh and write `playwright/.auth/user.json`. Use on first run, after credentials change, or when the dev environment's session storage was cleared. |
| `playwright.config.no-setup.js` | Skips global setup; relies on the existing `playwright/.auth/user.json`. Faster and recommended for iterative development. If you see "context closed" errors, fall back to the default config to refresh the auth file. |

## Environment

Tests target `https://nikitad-dev.torn.com` (set in both configs as `baseURL`). To target a different host, edit the `baseURL` in the config you're using.

## Conventions

- **Selectors**: prefer accessible queries (`getByRole`, `getByLabel`) where possible; fall back to CSS selectors for game-specific markup.
- **Skip vs fail**: tests `test.skip()` themselves when prerequisites aren't met (account not abroad, no admin role, no recipient with negative balance, etc.) rather than falsely failing.
- **Page definitions**: shared in [`e2e/money-input/pages.ts`](e2e/money-input/pages.ts) — one `PageDef` per money-input surface. Tag entries with `traveling: true` and/or `sanityOnly: true` when applicable.

## Authentication state

`playwright/.auth/user.json` is generated by `global-setup.js` on first run; it is gitignored and contains session cookies. The dev box also requires HTTP Basic Auth — credentials come from `.env`.
